# Dalvik Opcodes Documentation

This directory contains categorized documentation for Dalvik bytecode opcodes.

## Categories

1. [**Basic & System**](./opcodes/basic.md) - Housekeeping and debug operations (`nop`, etc.).
2. [**Move Operations**](./opcodes/moves.md) - Transfer data between registers.
3. [**Constants**](./opcodes/consts.md) - Load literal values into registers.
4. [**Control Flow**](./opcodes/flow.md) - Jumps, branches, returns, and switches.
5. [**Objects & Arrays**](./opcodes/objects.md) - Operations on objects, arrays, and monitors.
6. [**Method Invocation**](./opcodes/invokes.md) - Calling methods (virtual, static, direct, etc.).
7. [**Field Access**](./opcodes/fields.md) - Reading and writing instance and static fields.
8. [**Arithmetic & Logic**](./opcodes/arithmetic.md) - Mathematical, bitwise, and comparison operations.
9. [**Type Conversion**](./opcodes/conversion.md) - Converting between primitive types.
10. [**Pseudo-Instructions**](./opcodes/pseudo.md) - Special payloads for switches and arrays.
