# Type Conversion Opcodes

Converting between primitive types.

| Opcode | Name | Description |
|--------|------|-------------|
| 0x81 | OP_INT_TO_LONG | Convert int to long. |
| 0x82 | OP_INT_TO_FLOAT | Convert int to float. |
| 0x83 | OP_INT_TO_DOUBLE | Convert int to double. |
| 0x84 | OP_LONG_TO_INT | Convert long to int. |
| 0x85 | OP_LONG_TO_FLOAT | Convert long to float. |
| 0x86 | OP_LONG_TO_DOUBLE | Convert long to double. |
| 0x87 | OP_FLOAT_TO_INT | Convert float to int. |
| 0x88 | OP_FLOAT_TO_LONG | Convert float to long. |
| 0x89 | OP_FLOAT_TO_DOUBLE | Convert float to double. |
| 0x8a | OP_DOUBLE_TO_INT | Convert double to int. |
| 0x8b | OP_DOUBLE_TO_LONG | Convert double to long. |
| 0x8c | OP_DOUBLE_TO_FLOAT | Convert double to float. |
| 0x8d | OP_INT_TO_BYTE | Convert int to byte. |
| 0x8e | OP_INT_TO_CHAR | Convert int to char. |
| 0x8f | OP_INT_TO_SHORT | Convert int to short. |
